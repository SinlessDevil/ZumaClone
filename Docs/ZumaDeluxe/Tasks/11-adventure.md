# 11 · Adventure, жизни и набор карт

После 09–10. Наполнение карт использует монеты и усиления из 07–08. `LevelService`, прогресс игрока, окна результата и текущая карта кампании — точки интеграции.

- Ввести уровень, этап и храм, таблицы порядка и точки сохранения. Сверить стартовое число жизней, начисление за пороги, что происходит со счётом при смерти, Continue, Game Over и повтор старого этапа.
- Вести отдельно выбранный уровень, максимальную разблокировку, текущую попытку кампании и рекорды. Определить момент открытия карты для Gauntlet. Подготовить загрузку старого прогресса без потери уже пройденных уровней.
- Составить каталог карты → этап → правила сложности: трассы, цвета, скорость, цель шкалы, Ace Time, точки монет и параметры усилений. Учесть повторное использование трасс с другими настройками, типы геометрии и финальную Space. Фиксировать список карт по оглавлению и проверкам 00. Для проекта использовать собственные префабы и визуальные ресурсы.
- После проверки первой серии настроить полную последовательность, переходы храмов, финал и экран завершения. Завершение последней доступной главы должно обрабатываться явно.

**Готово, когда** игрок проходит несколько уровней, теряет и получает жизнь, возобновляет сохранённый этап, открывает карту для Gauntlet и завершает кампанию без перехода к отсутствующей главе. Старое сохранение загружается на совместимом маршруте.
