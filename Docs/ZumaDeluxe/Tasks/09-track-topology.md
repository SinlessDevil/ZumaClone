# 09 · Две трассы, туннели и скрытая трасса

После 02–03 и 06, затем повторить проверки 07–08 на двух трассах. Сохранить редактирование сплайна через PathCreator. Старт — `LevelHolder`, `LevelHolderEditor`, `LoadLevelState`, цепочка, карта и логика финиша.

- Описать для карты один или несколько маршрутов с собственным входом, черепом, очередью и интервалами видимости. Поддержать существующие prefab с одним маршрутом.
- Хранить расстояние относительно выбранного маршрута. Совпадение и притяжение происходят по соседям своей цепочки; выстрел учитывает все доступные маршруты.
- Сверить правила туннеля на входе, внутри, на выходе и у шара, частично видимого на границе. Движение внутри сохраняет порядок. Правила попадания, Gap Bonus и взрыва по радиусу согласованы с эталоном.
- Один общий результат уровня учитывает все потоки, достижение любого черепа и зачистку обеих трасс. Отдельно проверить карту Space как вариант отображения трассы.

**Готово, когда** автор уровня может собрать спираль, двухмаршрутную карту и участок туннеля из данных. PlayMode проверяет независимость потоков, пересечение видимых рядов, исчезновение/появление в туннеле и победу после очистки обоих маршрутов.
