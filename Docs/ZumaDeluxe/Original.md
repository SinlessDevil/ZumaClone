# Zuma Deluxe для Steam

Референс — Windows-версия **Zuma Deluxe**, Steam App ID 3330. Страница PopCap/EA подтверждает match-3, череп, Adventure и Gauntlet. Детальные правила ниже взяты из PC readme PopCap/GameHouse. Документ относится к изданию 2003–2004 годов и размещён на сторонней площадке. Числа из него требуют сверки с конкретной Steam-сборкой перед фиксацией в настройках. [Steam](https://store.steampowered.com/app/3330/Zuma_Deluxe/) · [PC readme, разделы How To Play / Scoring / Gameplay Tips](https://www.scribd.com/document/26206789/Zuma-Deluxe-Copyright-2003-2004-PopCap)

Steam описывает 3D-ускорение графики и эффектов. В PC readme настройка аппаратного ускорения указана как способ повысить производительность. Для переноса в Unity эталон — наблюдаемое поведение шаров на поле. В Steam сверяем спорные правила и тайминги. Xbox-руководство и записи прохождений помогают выбрать сценарии. [Steam](https://store.steampowered.com/app/3330/Zuma_Deluxe/) · [PC readme, Options](https://www.scribd.com/document/26206789/Zuma-Deluxe-Copyright-2003-2004-PopCap)

## Как играется попытка

| Механика | Правило и что ещё сверить |
| --- | --- |
| Прицел и запас | Мышь задаёт направление. ЛКМ стреляет, ПКМ меняет текущий и запасной цвета. Быстрый второй выстрел открывает тактики с монетой или дальним рядом. Измерить интервал, количество одновременно летящих шаров и выбор боеприпаса после исчезновения цвета. |
| Вставка и группы | Вставка в подвижный ряд, взрыв непрерывной группы из трёх или более одинаковых. Одинаковые края разрыва притягиваются и могут вызвать следующий взрыв. Для разных цветов проверить, когда передний сегмент останавливается и как его догоняет хвост. |
| Три вида отката | Локальное притяжение на стыке, откат при заполнении шкалы и бонус Reverse — разные причины движения. В подсказках readme откат шкалы связывается с прохождением половины трассы. Проверить границу и поведение двух трасс. |
| Zuma Meter | Набранные в игре очки заполняют шкалу. После порога подача прекращается и остаётся зачистить поле. Сверить вклад каждого типа очков и продолжение движения цепи после краткого отката. |
| Поражение | Достаточно одного шара у черепа, чтобы потерять жизнь. Оставшиеся шары поглощаются. Проверить повтор уровня, состояние счёта после смерти и приоритет попадания на том же кадре. |
| Усиления | Временно помеченный шар активирует эффект при удалении в группе. Четыре эффекта: замедление, движение назад, взрыв по радиусу, луч и более быстрая стрельба. Сверить длительность меток, повторное применение и активацию усиления соседним взрывом. |
| Монеты | Появляются на поле и сбиваются выстрелом. Цепочка может закрывать путь к цели. Проверить исчезновение, поведение снаряда после попадания и цену последующих монет. |
| Трассы | В PC readme описаны две независимые кривые с отдельной подачей. На картах с несколькими рядами выстрел может пройти через ближний разрыв в дальний ряд. Туннели, границы зоны попадания и скрытая трасса в Space подлежат сверке на записи или в игре. |
| Финиш | Очки за оставшийся путь от последнего уничтоженного шара до черепа и отдельная премия за Ace Time. В PC readme также указан показ остатка времени по клавише T. |
| Adventure | Храмы → этапы → уровни, сохранение рубежей этапов, открытие карт для Gauntlet и потери жизней. Сверить стартовые жизни, Continue и повторное прохождение этапа по Steam. |
| Gauntlet | Открытые карты, фиксированная или случайная карта, Practice с повторными прохождениями и Survival с растущей сложностью потока. Ранги от Rabbit до Sun God и награда за карту. Сверить пороги рангов и цикл шкалы в каждом режиме. |

Правила для таблицы и числовые ориентиры. [PC readme PopCap](https://www.scribd.com/document/26206789/Zuma-Deluxe-Copyright-2003-2004-PopCap) · [Официальное руководство PopCap Arcade Vol. 1, Zuma, стр. 6–7](https://static-www.ec.popcap.com/support.popcap.com/sites/support.popcap.com/files/XBox_Vol1_manual.pdf#page=5). Руководство Xbox подтверждает общую механику и роль бонусов в заполнении шкалы. Управление и баланс PC проверяются отдельно.

## Очки по PC readme

- Удаление — 10 за шар. **Combo** — каскад от одного выстрела. Для второго, третьего и четвёртого взрыва указаны добавки 100, 200 и 300.
- **Chain** — серия разных успешных выстрелов. Для пятого, шестого и седьмого указаны 100, 110 и 120. Это отдельное событие от Combo.
- **Gap** — результативный выстрел через ограниченный шарами разрыв. Ориентир 10–500 очков, до 250 в Survival. Узкий проход ценится выше. Для нескольких проходов описано умножение лучшего бонуса на их число.
- **Coin** — ориентир 1/6 порога шкалы с округлением вниз до сотни, минимум 500 в Adventure/Practice и 200 в Survival. В раннем разделе упомянут рост награды за несколько монет без явной формулы.
- **Distance** — ориентир 100 очков за 60 пикселей оставшегося пути. Пересчёт из пикселей в единицы Unity требует калибровки. **Ace Time** — раздел Scoring описывает базовые 100 за достижение порога и долю выигранного времени от 25 000 очков. Раздел How To Play описывает бонус через секунды, поэтому формулу и граничные случаи проверяем на Steam.
- **Жизни** — ориентир одна дополнительная за каждые 50 000 очков в накопительном счёте.

Источник чисел. [PC readme, Scoring и Gameplay Tips](https://www.scribd.com/document/26206789/Zuma-Deluxe-Copyright-2003-2004-PopCap)
