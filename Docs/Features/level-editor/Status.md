# Level Editor

Готово к ревью. Ветка `feature/level-editor` создана от `dev/dev-1.0.0`. Реализация следует утверждённому плану и эскизу из чата.

## Что работает

- **Tools → Level Editor** открывает первый уровень кампании. Слева доступны чаптеры, сверху — список, создание через мини-окно и удаление выбранного уровня с подтверждением. Можно править имя, ID и чаптер. В редакторе можно создать чаптер и назначить ему Temple ID.
- На полотне XZ редактируются опорные точки и ручки Безье. Shift-клик по дороге вставляет точку, жаба двигается отдельно, ворота двигаются вместе с концами дорожки и поворачиваются по ней. Перетаскивание и изменение метаданных поддерживают Undo. Справа выбираются текстуры поля и дороги. Окно рассчитано на одну трассу на уровень. [Снимок окна](C:/Users/qwamo/Documents/Codex/2026-11-12/yf/level-editor-verification/level-editor.png)
- Один общий `Level.prefab` сохранил GUID исходного базового префаба. Сервис применяет геометрию, точки монет и текстуры при загрузке, собирает меш дороги на готовом объекте префаба, затем игра спавнит жабу и запускает цепочку. Три исходных ассета уровней сохранили ID и настройки баланса. [Общий префаб](../../../Assets/Resources/Levels/Level.prefab) · [Статик дата](../../../Assets/Resources/StaticData/Levels)
- Прогресс ищет уровень по паре «чаптер + ID». Следующий уровень берётся по порядку списка. Если ключ удалён, выбирается ближайший доступный. Освобождённые ключи зарезервированы, чтобы старый прогресс случайно не перешёл на новый уровень. Для смены ID или чаптера окно запрашивает подтверждение.
