В сцене Unity цепь движется по расстоянию вдоль PathCreator. Контакты и вставка вычисляются в XZ. Камера и визуальные размеры моделей не участвуют в игровых проверках. Порог шкалы для старых ресурсов берётся из `CountItem × ScorePerItem` с минимумом 100. Темп выстрелов, частота и длительность бонусов, ранги, позиции двух монет и форма текущей спирали — настройки для существующего проекта. Значения Ace Time на картах ожидают замеров.

## Проверки

Unity **6000.5.3f1**. До очистки временных проверок прошли **11 PlayMode** и **22 выбранных EditMode**. Временные сценарии покрыли контакт по отрезку полёта, остановку подачи, Accuracy, два маршрута и туннель, раздельный прогресс Gauntlet и рекорд при повторе. После прогона эти шесть сценариев удалены. Существующий тест каскада обновлён под добавку Combo вместо ×2 и проверяет окончание анимации отдельно.

Дымовой сценарий прошёл через штатный `Initial → Game`. Проверены выстрел через игровой ввод, монета с начислением очков, пауза, отмена старой попытки и переход `Survival → Random` из меню с открытой картой. Временный PlayerPrefs восстановлен. После очистки временных тестов компиляция прошла без ошибок.

После очистки прошли **7 PlayMode** и **29 выбранных EditMode** без падений и пропусков. Повторный дымовой сценарий прошёл на финальном дереве. В Unity Console нет ошибок. Сохранённые журналы содержат предупреждения компилятора и существующие предупреждения Zenject/аудио.

XML и логи сохранены в рабочей папке текущего чата. Отдельно проверены сцены из Build Settings. Точная сверка с установленным Zuma Deluxe, физический Android и полная кампания остаются открытыми.
