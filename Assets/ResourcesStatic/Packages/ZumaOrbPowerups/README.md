# Текстуры бонусных шаров Zuma Frog

Комплект использует ту же UV-развёртку `MagicOrb` и тот же способ перекраски, что и `ZumaOrbTextures`. Цвета на превью приведены для примера. Знак повторяется по бокам и на полюсах, чтобы его можно было увидеть сверху и при вращении шара.

| Папка | Знак | Эффект, который он обозначает |
| --- | --- | --- |
| `Reverse` | Двойная стрелка | Цепочка временно движется назад |
| `Slowdown` | Две полоски | Цепочка временно замедляется |
| `Accuracy` | Прицел | Появляется линия прицеливания |
| `Explosion` | Вспышка | Взрыв убирает соседние шары |

## Подключение карт

В каждой папке три PNG 1024 × 512. Для всех карт используйте UV0, масштаб 1 × 1, смещение 0 × 0, `Repeat` по U и `Clamp` по V.

- `*_BaseColor.png` — нейтральный цвет. Подключите в Base Map с sRGB и умножьте на цвет игрового шара.
- `*_Normal.png` — tangent-space normal map (+Y). В Unity выберите тип `Normal map`. Оставьте `Create from Grayscale` и `Flip Green Channel` выключенными.
- `*_RuneMask.png` — маска свечения символа со слабым свечением ободка. Отключите sRGB и умножьте маску на цвет и интенсивность свечения.

`Previews/Palette.png` показывает варианты цвета сбоку. `Previews/SameColor_Top.png` показывает все бонусы в одном цвете сверху. Карты проверены на исходном меше шара в Blender.
