# Текстуры для снарядов Zuma Frog

Четыре рисунка для сферической UV-развёртки `MagicOrb`. Солнце (`Sun`), волна (`Wave`), листья (`Leaf`) и лабиринт (`Labyrinth`). Цвета на превью подобраны как примеры. Любой рисунок можно использовать с любым цветом.

В каждой папке три PNG 1024 × 512.

| Файл | Назначение |
| --- | --- |
| `*_BaseColor.png` | Нейтральная текстура для Base Map. Оставьте sRGB включённым и задайте цвет материала. |
| `*_Normal.png` | Готовая tangent-space normal map (+Y) для выпуклых рун. В Unity задайте тип `Normal map`, оставьте `Create from Grayscale` и `Flip Green Channel` выключенными. |
| `*_RuneMask.png` | Белое выделяет руны. Подключите как линейную маску с выключенным sRGB и умножьте на цвет свечения. |

Для всех трёх карт используйте UV0, масштаб 1 × 1 и смещение 0 × 0. По U используйте `Repeat`, по V подойдёт `Clamp`. Для начала выставьте Normal Strength 1 и Smoothness около 0,68. Чтобы цвет шара и свечение менялись вместе в Shader Graph, умножьте `BaseColor` и `RuneMask` на один параметр цвета. Для свечения используйте отдельный множитель интенсивности.

В `Previews/NormalComparison.png` показан серый шар под одинаковым светом с выключенной и включённой normal map. Карты проверены в Blender на UV существующего шара. Импорт в Unity не запускался. [Настройки текстур Unity](https://docs.unity3d.com/6000.0/Documentation/Manual/class-TextureImporter.html)
