# ZumaClone — материалы храмов

Пять наборов по два материала. Каждый `Ground` — квадратный тайл с повтором по U и V. Каждый `Track` — профиль поперёк дорожки с повтором вдоль неё. Поставляемые карты имеют разрешение 1024×1024. Папка `Previews` показывает освещение, сетку 2×2 и примеры прокладки дорожки.

## Референсы и художественные решения

| Референс | Пол и мелкие детали | Дорожка и освещение | Декор |
|---|---|---|---|
| Бордовый храм | Зернистый красный камень, тёмные пятна, эрозия и трещины | Тёплая светлая кромка, тёмные стенки и заполированное дно | Отдельные спирали и фрагменты орнамента |
| Холодный храм | Сине-серый сланец с волнообразными слоями и локальным рельефом | Плавный профиль, холодные блики на кромке | Резьба может оставаться редкой, чтобы шарики хорошо читались |
| Песчаник | Охра, пыль, трещины и широкие поверхности со сдержанным рельефом | Утопленный желоб с чёткой обработанной кромкой | Крупная геометрическая розетка отдельным слоем |

Два новых варианта — нефритовое святилище с зелёной патиной в трещинах и бронзовые руины из тёплого бурого камня. У «бронзовых руин» название описывает палитру, поэтому материал остаётся диэлектриком. Маски `Decorations` содержат спираль, розетку, трещину, окантовку, четыре глифа и угловой орнамент. Белое отмечает место нанесения, чёрное — остальную область. Они предназначены для отдельной декали или маски в шейдере.

Характер зерна, выветривания и трещин сверял по ресурсам CC0. Поставляемые пиксели полностью процедурные. [Poly Haven — Sandstone Cracks](https://polyhaven.com/a/sandstone_cracks), [Poly Haven — Red Sandstone Wall](https://polyhaven.com/a/red_sandstone_wall), [Poly Haven — Mossy Sandstone](https://polyhaven.com/a/mossy_sandstone), [ambientCG — Rock 030](https://ambientcg.com/view?id=Rock030), [ambientCG — лицензия](https://docs.ambientcg.com/license/).

## Генерация

Нужны Python 3.10+, NumPy, SciPy и Pillow. Подойдёт локальное Python-окружение ComfyUI, в нём эти зависимости уже установлены. Сервер ComfyUI для генерации не требуется. Запускать из папки пакета.

```powershell
python -B generate.py --size 1024
python -B preview.py
python -B generate.py --theme SandstoneTemple --size 2048 --seed 906 --output Sandstone_2048
```

`themes.json` задаёт параметры темы. Для новой темы скопируйте запись, задайте новый ключ и эти поля.

| Поле | Назначение |
|---|---|
| `label`, `style` | Название на превью и семейство рельефа. Доступны `sandstone`, `volcanic`, `slate`, `jade`, `bronze`. |
| `seed` | Зерно генератора. Параметр `--seed` переопределяет его. |
| `palette`, `track` | По три цвета sRGB HEX от тени к светлому тону. |
| `roughness`, `detail` | Базовая шероховатость в диапазоне 0–1 и множитель мелкого рельефа. |
| `cracks`, `ornaments` | Интенсивность трещин и акцент продольной резьбы на дорожке, 0–1. |
| `width`, `depth`, `edge` | Относительная ширина для расчёта нормалей дорожки, глубина и округлость её профиля. Физическую ширину задаёт меш в Unity. |
| `--size` | 256, 512, 1024 или 2048 px. Частота мелкого зерна ограничивается разрешением. |

Генератор смешивает периодический шум, деформированные границы ячеек, локальные сколы и слоистость. Дорожка дополнительно получает поперечный профиль с дном, стенками, округлой кромкой и потёртыми краями. Нормали вычисляются центральными разностями карты высот. Для повторяющихся осей разности проходят через границу тайла. Цвет, нормаль и локальное AO можно пересчитывать отдельно при изменении параметров темы.

## Подключение к ZumaClone

В проекте Unity 6000.5.3f1 и URP 17.5.0. `LevelHolder` уже ссылается на `RoadMeshCreator`. У существующей верхней части меша U идёт поперёк, V берётся из `Path.times`, а `Path.times` вычисляется через накопленную длину. `Level 1.prefab` уже назначает материал в `roadMaterial`. Новый материал дорожки можно подключить на это место. Для одинакового мирового масштаба повторения на разных трассах задайте `textureTiling = path.length / repeatLength`. Текущий код меняет масштаб общего материала, поэтому для разных значений одновременно используйте отдельные экземпляры материалов.

| Карта | Импорт и слот URP/Lit |
|---|---|
| `BaseColor.png` | Default, sRGB, Base Map |
| `Normal.png` | Normal map, без конвертации из grayscale. Tangent space +Y, начальное значение Bump Scale 1. |
| `MetallicSmoothness.png` | Default, linear, сохранять исходную альфу. Workflow Metallic, слот Metallic Map, источник Smoothness — Metallic Alpha. R равен 0, A равен 1 − Roughness. |
| `AO.png` | Default, linear, Occlusion Map. В grayscale значение одинаково во всех цветовых каналах. |
| `Height.png` | Линейный 16-битный источник рельефа. Подключать только при наличии шейдера или этапа, который читает высоту. |
| `Roughness.png` | Линейная исходная карта для инструментов, работающих с roughness. В URP/Lit используется альфа упакованной карты. |

Для пола выставьте Wrap Mode Repeat по U и V. Для дорожки выставьте Per-axis, U Clamp, V Repeat. Включите mipmaps для игровых карт. Для уже созданного процедурного меша проверьте наличие тангенсов. В прочитанном `RoadMeshCreator.cs` записываются позиции, UV и нормали, а пересчёта тангенсов нет. В варианте меша с нормалями добавьте `_mesh.RecalculateTangents()` после назначения всех индексов подмешей и проверьте освещение на изгибе. [Unity — URP Lit](https://docs.unity.com/en-us/engine/6000.0/manual/materials-and-shaders/built-in/shaders-in-universalrp/reference/lit-shader), [Unity — Normal Map Import Settings](https://docs.unity.com/en-us/engine/6000.0/manual/materials-and-shaders/textures/textures-reference/texture-type-normal-map).

На примерах дорожка строится по демонстрационным траекториям. В текущем наборе глубина желоба передаётся картами. Настоящее углубление в геометрии потребует поперечных рядов вершин в существующем `RoadMeshCreator` и отдельной проверки перекрытий на сплайнах. Ассеты, код и префабы ZumaClone остались без изменений. Импорт и рендер в Unity Editor не проверялись.

## Проверка

`Materials/SeamCheck.json` содержит для 1024 px отношение RMS-перепада на стыке к RMS-перепаду соседних пикселей внутри изображения. Для пола записаны V и U, для дорожки только V. Генератор прерывается, если отношение превышает 1,75. Проверяются также единичная длина нормалей с допуском на 8-битное квантование и точное совпадение канала smoothness с инверсией экспортированной roughness. Проверка на шов дополнена визуальным повтором 2×2.

Все пять пар прошли проверки при 256, 512, 1024 и 2048 px. При повторной генерации песчаника на 1024 px совпали SHA-256 всех 12 PNG. В пакете есть 1024 px карты и превью песчаника, построенное из отдельно сгенерированных 512 px карт.
